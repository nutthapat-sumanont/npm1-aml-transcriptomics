# Project: NPM1-mutated vs wild-type AML (Beat AML 2.0)

## Goal
Compare gene expression between NPM1-mutated and NPM1-wild-type AML using Beat AML 2.0 raw counts, then connect the result to menin inhibitor biology. This is a learning and portfolio project. I'm a first-year HKU BSc student with basic R and Python.

## Decisions so far (check against these every session)
- Cohort (done in Session 1, scripts/02_cohort.R): AML only, initial diagnosis, de novo only, one sample per patient (earliest), NPM1 from the clinical summary consensus call. Excluded APL and KMT2A fusions. Main cohort was 277 patients after Session 1 (100 NPM1-mutated, 177 wild-type); 276 after the Session 2 QC (see below). `main_cohort == TRUE` in results/cohort.csv.
- KMT2A fusion cases stay in cohort.csv (`group = "KMT2A_r"`) for a later three-group plot of HOXA9 and MEIS1: NPM1-mutated, KMT2A-rearranged, other AML.
- The 8 wild-type samples with KMT2A-PTD in their notes stay in the main cohort (PTD isn't tested consistently in Beat AML).
- DESeq2 design (approved after Session 2 QC): ~ wave + specimen_type + sex + NPM1_status, NPM1 wild-type as the reference level. Wave keeps three levels (Waves1+2, Waves3+4, Both). specimen_type is two levels, BM and Blood; leukapheresis counts as Blood.
- BA2294R dropped (recorded female, expression male; possible sample swap). Main cohort is now 276 patients: 100 NPM1-mutated, 176 wild-type. It stays in cohort.csv with `main_cohort = FALSE` and `group = "QC_excluded"` (step 9 in scripts/02_cohort.R).
- Sensitivity analysis: rerun with FLT3-ITD added (~ wave + specimen_type + sex + FLT3_ITD + NPM1_status) and compare top genes. The main model stays without FLT3-ITD.
- Before enrichment, remove chrY genes and XIST from the ranked list (approved after Session 3), because a sex-adjusted model still can't handle Y genes with near-zero counts in females (RPS4Y1 and KDM5D looked "down" because of one female sample, BA3206R). "chrY" means the male-specific region only; pseudoautosomal (PAR1/PAR2) genes are on X and Y in both sexes and stay. This removes 26 of 19,398 genes (25 chrY + XIST), leaving 19,372. The chrY list comes from Ensembl GRCh37 and is saved in results/chrY_genes_grch37.csv (scripts/05_enrichment.R step 1).
- NEK10/FTO/USP44 group definition (changed after Session 7, applied in Session 8): three genes only, NEK10, FTO and USP44. WDR86 is dropped because it tracks FLT3-ITD, not the module. Core score = mean z-score of the three genes (VST) across the 100 NPM1-mutated samples; high/low = two-cluster k-means on that score (seed 2026), in scripts/05_enrichment.R step 8. Split: 37 high, 63 low (the old four-gene split was 39/61; 4 samples changed group, listed in results/block_split_changes.csv). `block_group` in results/block_nek10_fto_scores.csv is this split; `group_4gene` is kept only for comparison.
- Subgroup sensitivity DESeq2 (approved in Session 5, scripts/06b_deseq2_subgroups.R): an extra model only, the main model is unchanged. Three-level group from the k-means split of the three-gene NEK10/FTO/USP44 score: NPM1 wild-type (reference), NPM1-high (primitive-like, n = 37), NPM1-low (committed-like, n = 63); design ~ wave + specimen_type + sex + group. Outputs results/deseq2_subgroups.csv and figures/06_subgroup_shared_vs_specific.png.
- The NEK10/FTO/USP44-high group matches published subgroups (Mer et al., Nat Commun 2021 "primitive"; Arza-Apalategi et al., Leukemia 2023, IFEX9-high). Describe it that way, not as a new finding. Gene-level counts can't separate FTO from IFEX9.
- Cell-type sensitivity DESeq2 (approved in Session 6, scripts/07_cell_composition.R): extra models only, the main model is unchanged. Uses the Bottomly et al. 2022 malignant cell-type scores (beataml2_manuscript_vg_cts.xlsx; PC1 of the top 30 van Galen et al. 2019 marker genes per cell type). Only 270 of 276 main-cohort samples have scores (none of the wave "Both" samples, so wave has two levels in these models). Three fits on the same 270: (1) the main design refit, for a fair comparison; (2) the sensitivity model, ~ wave + specimen_type + sex + HSC_like + Monocyte_like + NPM1_status; (3) all six scores, which is an UPPER BOUND only, never reported as a result (the six scores predict NPM1 status with AUC 0.93, so it removes NPM1 biology too). Lead with the two-score model in write-ups. Any positive control that is one of the genes behind a score in the model (MEIS1 is in the HSC-like signature) is flagged as partly circular.
- TCGA-LAML replication (approved in Session 7, scripts/08_tcga_replication.R): NPM1 from the TCGA paper's curated calls (cBioPortal laml_tcga_pub); where paper and clinical NPMc test disagree, keep only if GDC's masked MAF confirms the paper call. KMT2A-r from the paper's curated cytogenetics/rearrangements plus GDC karyotype and MLL FISH (>= 20% cells). TCGA-AB-2869 dropped (lab PML-RARA positive but FAB M2, normal karyotype). Main cohort 111 (31 NPM1-mutated, 80 wild-type), 9 KMT2A-r. Design ~ sex + NPM1_status (no wave or specimen type in TCGA; plate checked by PCA, not in the model); FLT3-ITD sensitivity run alongside.
- TET2, IDH1 or IDH2 in the high vs low group (Session 8, scripts/06_subgroup.R step 1d) is a consistency check, not an independent test: the idea came partly from Beat AML itself and was formed after looking at TCGA.
- Drug response (Session 8, scripts/09_drug_response.R): Beat AML ex vivo AUC (lower = more sensitive), matched to the same specimen as RNA-seq only (join on dbgap_rnaseq_sample). Analysis set = main-cohort samples with same-specimen drug data and a monocyte-like score. Per drug: auc ~ NPM1_status + Monocyte_like, BH across drugs, drugs with fewer than 20 tested samples per group skipped. Subgroup and HOX-score drug analyses are report only. No menin inhibitor is in the Beat AML panel.
- Survival (Session 9, scripts/10_survival.R): exploratory only, because treatment varied a lot in Beat AML. Overall survival = `overallSurvival` (days from study inclusion, which is the diagnostic sample day for the main cohort) with `vitalStatus` Dead as the event and Alive censored; Unknown status (1 patient) can't be used. Cox models: NPM1 + age; four NPM1 x FLT3-ITD groups + age; within NPM1-mutated, three-gene NEK10/FTO/USP44 high vs low + age + FLT3-ITD. TCGA repeat uses cBioPortal OS_MONTHS / OS_STATUS. Treatment is described, never put in a model.
- FTO vs IFEX9 (Session 10, scripts/11_fto_locus.R): in TCGA-LAML coverage (recount3, GRCh38, GENCODE v26) the NEK10/FTO/USP44-high "FTO" signal is IFEX9, a transcript starting in FTO intron 8 (exon 1 chr16:54063753-54063943 GRCh38, from the paper's supplement) and spliced onto FTO exon 9. FTO exons 1-8 and the canonical FTO junctions are not higher. Ensembl 75 lists IFEX9 as FTO-007 (ENST00000472835), so Beat AML's "FTO" gene count includes it. Write "FTO locus / IFEX9", not "the FTO enzyme".
- Project web page (Session 11, scripts/12_build_site.R): static site in docs/ (plain HTML/CSS/JS, Plotly from cdn.plot.ly), served by GitHub Pages from main /docs. Three pages: overview (index.html), results (results.html), gene lookup (lookup.html). Captions state only what LEARNING.md says. The overview summary paragraph is a marked placeholder for me to write. The lookup stores per-group box-plot summaries only (quartiles and whiskers, VST from the Session 4 three-group set), never per-sample values. Keep docs/ under 20 MB.
